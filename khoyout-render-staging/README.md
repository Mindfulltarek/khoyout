# خيوط — متجر إلكتروني ولوحة إدارة

مشروع متجر عربي متجاوب، مع خادم يدير بيانات الكتالوج والمصادقة ولوحة الإدارة. يبدأ تشغيل المتجر ببيانات الكتالوج الابتدائية، ويمكن الحفاظ على نسخة آمنة من الكتالوج في ملف قاعدة البذرة.

## التشغيل المحلي

يتطلب المشروع Node.js 20 أو أحدث.

```bash
npm ci
cp .env.example .env
```

أدخلي بيانات Google OAuth والبريد الذي سيُمنح صلاحية الإدارة في ملف `.env` المحلي فقط. لا ترفعي هذا الملف إلى مستودع، ولا ترسلي القيم السرية في المحادثة.

```bash
npm run dev
```

يفتح المتجر محليًا على:

```text
http://localhost:5173
```

وتفتح لوحة الإدارة على:

```text
http://localhost:5173/admin
```

## متغيرات الخادم

تُحفظ بيانات المصادقة في الخادم فقط، ولا تستخدم الواجهة الأمامية أسرار OAuth.

```text
OWNER_ADMIN_EMAIL
GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET
```

لعنوان الاستضافة المحلي أو عنوان استضافة آخر:

```text
APP_BASE_URL
```

على Render يكتشف الخادم عنوان الخدمة تلقائيًا من متغير البيئة الذي توفره المنصة، ما لم يُضبط `APP_BASE_URL` يدويًا.

## المعاينة العامة على Render

يوجد إعداد نشر في:

```text
render.yaml
```

الإعداد ينشئ خدمة ويب مجانية في فرانكفورت، ويُبقي إنشاء الطلبات معطلًا. يظل دخول Google والتحقق من صلاحية الإدارة محميين من الخادم.

قبل تسجيل الدخول على النطاق الجديد، أضيفي عنوان الرجوع المطابق في إعدادات عميل Google:

```text
https://<عنوان-الخدمة>.onrender.com/api/auth/google/callback
```

خطة Render المجانية تُوقف الخدمة بعد 15 دقيقة من الخمول، كما أن ملفاتها المحلية مؤقتة. لذلك قد تحتاجين إلى تسجيل الدخول مجددًا بعد إعادة تشغيل الخدمة، وأي تعديلات محلية على بيانات المعاينة لا تبقى بعد الإيقاف أو إعادة النشر. لا يتضمن الإعداد قرصًا مدفوعًا أو قاعدة بيانات مدفوعة.

## قاعدة البذرة

الملف التالي يحتوي على بيانات الكتالوج وإعدادات واجهة المتجر فقط، ولا يحتوي على مستخدمين أو جلسات أو عملاء أو طلبات.

```text
data/khoyout.seed.sqlite
```

عند تشغيل المشروع لأول مرة دون قاعدة تشغيل، يستخدم الخادم هذه البذرة لإنشاء قاعدة العمل. قاعدة العمل وملفات البيئة مستثناة من الرفع في `.gitignore`.

## إنشاء نسخة الإنتاج

```bash
npm run build
npm start
```

استضافة الملفات الثابتة وحدها لا تشغّل خادم Express أو SQLite؛ يلزم تشغيل خدمة الخادم.
